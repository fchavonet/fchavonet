# Template - Licenses

## Description

A collection of reusable license templates for my projects.

These templates provide different levels of permissions and restrictions, allowing each project to adopt a license according to its intended use and distribution.

The following resources provide the official license texts and documentation for reviewing or updating these templates:

- **Proprietary:** Custom license. No official standardized reference.
- **MIT:** [Open Source Initiative](https://opensource.org/license/mit)
- **Apache 2.0:** [Apache Software Foundation](https://www.apache.org/licenses/LICENSE-2.0)
- **GPL 3.0:** [Free Software Foundation](https://www.gnu.org/licenses/gpl-3.0.html)
- **AGPL 3.0:** [Free Software Foundation](https://www.gnu.org/licenses/agpl-3.0.html)

## File Description

| **FILE**          | **DESCRIPTION**                                                                |
| :---------------: | ------------------------------------------------------------------------------ |
| `PROPRIETARY.txt` | All rights reserved. Restricts reuse, modification, and distribution.          |
| `MIT.txt`         | Permissive license allowing commercial use with copyright attribution.         |
| `APACHE-2.0.txt`  | Permissive license including an explicit patent grant and notice requirements. |
| `GPL-3.0.txt`     | Copyleft license requiring distributed derivatives to remain open source.      |
| `AGPL-3.0.txt`    | Copyleft license extending source-sharing obligations to network services.     |
| `README.md`       | The README file you are currently reading 😉.                                  |
